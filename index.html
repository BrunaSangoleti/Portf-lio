🗺️ Mural de Missões

Missão: Sistema de agendamentos empresa CarePlus

O projeto visa solucionar o alto índice de no-show nas clínicas da CarePlus, que gerava custos desnecessários e ociosidade médica. A solução entregue é um portal web responsivo que transforma a experiência de agendamento. Para garantir o comparecimento do paciente, o sistema oferece integração com rotas em tempo real, análise climática e links diretos para Waze, Maps e Google Agenda. Além de remover o atrito do deslocamento, a plataforma garante o engajamento contínuo por meio de um sistema de gamificação e um mascote interativo, ambos alinhados à missão corporativa da empresa.

Runas: HTML, CSS, JavaScript e Bootstrap.

Missão: Fintech para controle de gastos

Este projeto é uma plataforma Fintech concebida para combater o endividamento por meio da conscientização financeira. A solução ajuda os usuários a rastrearem seus gastos, facilitando a economia e a construção de patrimônio. Do ponto de vista técnico, trata-se de uma aplicação Full Stack composta por uma interface web responsiva e uma API backend em Java. A arquitetura inclui um sistema CRUD completo para o processamento e cálculo das finanças, autenticação segura de login, tratamento abrangente de exceções e persistência de dados estruturada em um banco Oracle SQL.

Runas: React.js com Vite, Tailwind CSS, Axios, Recharts, React Hook Form + Zod, ava 21 com Spring Boot,Spring Security + JWT, Spring Data JPA + Hibernate, Docker, Flyway.

Missão: FoodRescue (App Android)

Plataforma focada em ESG, atacando o desperdício de alimentos e a insegurança alimentar. Usando geolocalização, conecta estabelecimentos locais e pessoas com alimentos excedentes diretamente com ONGs. Focada na transparência e dignidade na doação, a plataforma permite que as instituições escolham os itens que realmente atendam às suas necessidades. O app gera relatórios e métricas em tempo real, mostrando o impacto de cada resgate (refeições salvas, famílias ajudadas e CO2 evitado).

Runas: Kotlin, Jetpack Compose, Android Studio, Git/GitHub.
